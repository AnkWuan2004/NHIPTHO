# C-011 — Migrate DHT22 alarm firmware to ESP32-S3 DevKit

status: done
deps: C-010
implements: FR9
risk: standard
risk-reason: Changing only the microcontroller target and documented wiring can make the firmware fail to compile or drive the wrong physical outputs if the board target and GPIO mapping drift.
risk-ack: none

## Scope

Migrate the existing DHT22 local-alarm firmware from ESP32 DevKit V1 to an ESP32-S3 DevKit target. Keep the API payload, alarm behavior, sampling interval, and fail-safe logic unchanged; set DHT22 DATA to GPIO38, the speaker/buzzer output to GPIO36, and the warning LED output to GPIO35. Update the Vietnamese wiring and board-selection instructions in README.md without claiming physical hardware proof.

## Independent test

An operator can select the ESP32-S3 DevKit, wire DHT22/speaker/warning LED to GPIO38/36/35, compile and flash the firmware, and observe the same local alarm behavior through the existing API path.

## Allowed files

`esp32devkit_dht22_alarm.ino`, `README.md`
